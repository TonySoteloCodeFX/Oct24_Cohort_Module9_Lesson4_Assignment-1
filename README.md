# Tech Solutions Website

This project is a responsive "Services" webpage for a fictional company, **Tech Solutions**, showcasing its services in Managed IT, Cybersecurity, and Software Development.

## Features
- **Responsive Design**: Optimized for desktops, tablets, and mobile devices.
- **Interactive Cards**: Flip animations reveal additional information about each service.
- **Gradient Text Styling**: Unique text gradient styles for headings.
- **Custom Fonts**: Leveraging Google Fonts for professional typography.
- **Smooth UI/UX**: User-friendly layout with easy navigation.

---

## Technologies Used
- **HTML5**: For the webpage structure.
- **CSS3**: Custom styles including animations and gradients.
- **Bootstrap 5**: For responsive layout and navigation bar.
- **JavaScript**: Bootstrap scripts for mobile responsiveness.
